# 🚀 Agora Vai

API Spring Boot com front-end simples e testes automatizados.

## About
🔵 Tecnologias
- Java 21
- Spring Boot 3
- Maven
- JUnit 5
- MockMvc

## ▶ Rodar aplicação
```bash
./mvnw spring-boot:run
```

Acesse: http://localhost:8080

## About
🔵 Rodar testes
```bash
./mvnw test
```

## About
🔵 Endpoint
```
GET /api/status/{nome}
```
